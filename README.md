## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Testing

Tests that touch a database use `DATABASE_TEST_URL` from `.env`. They refuse to run unless its database name contains "test" and differs from `DATABASE_URL`, and they apply the committed migrations to it automatically.

| Command | What it runs |
| --- | --- |
| `npm test` | Unit tests (Vitest), no database needed |
| `npm run test:integration` | Auth session and user code against the test database |
| `npm run test:e2e` | Playwright in Chromium against its own Next server (port 3100, build folder `.next-e2e`) and a fake Google token server; first run: `npx playwright install chromium` |

The e2e server can run next to `npm run dev`. The real Google consent screen is not part of the automated tests.
